# Codex Audit Working Agreements

## Insight Credibility

- Treat every insight as an evidence-backed hypothesis, not a verdict. Lead with the observed behavior, define domain terms in plain language, and explain why it can affect token use or context.
- Never present a detector threshold, byte count, or proxy metric as an inherent limit, exact token count, cost, or problem unless the underlying data proves it. State whether a number is measured, estimated, or a screening heuristic, plus its important limitations.
- Prefer concrete aggregate evidence—count, total, breakdown, and largest contributor—over a bare threshold. Use units people can interpret; when translating bytes to tokens, label it a rough text-dependent estimate.
- User-facing reports must say what data they include as well as what they exclude. Keep the privacy description specific and consistent with the saved snapshot.
